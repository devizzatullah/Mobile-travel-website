# desktop-travel-website
A clean, responsive, and minimal static mobile travel website built with HTML semantics and CSS styling. This project serves as a groundlaying template for personal travel blogs, agency landing pages or destination showcase websites, designed to be easy to customize and deploy.

## Assets: 
■ images, logos and icons 
■ custom web fonts 

## Features: 
■ Lightweight & Fast – Built with HTML and CSS.
■ Responsive Design – Works seamlessly on desktop, tablet and mobile.
■ Customizable – Easily modify colors, fonts and layout. 
■ Clean File Structure – Easy to navigate and maintain. 
■ Deploy-Ready – Works well on GitHub Pages.

## Technologies Used:
■ HTML – Semantic markup.
■ CSS – Modern responsive styling.

## Getting Started 
■ Clone the repository: git clone https://github.com/yourusername/Mobile-travel-website.git 
■ Navigate into the project: cd Mobile-travel-website
■ Open in your browser: Simply right-click index.html and click "open with live server"
■ Update text and images in index.html
■ Adjust styles in styles.css 

## Deployment: Deploy easily on GitHub Pages
